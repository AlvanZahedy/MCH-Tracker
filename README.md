# MCH-Tracker
A real-time tracker that uses the Hypixel API to extract information within a 5 second delay and outputs it through a Discord Bot. It can be relayed through any other medium of output, the Object "Tracker" effectively receives User ID and returns information through its various methods.
LAST UPDATED 2023 (The New API allows players to close certain features from their account hence rendering certain methods unavailable on said players)
